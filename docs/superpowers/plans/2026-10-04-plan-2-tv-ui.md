# Plan 2 — TV User Interface

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the phone-style UI on TVs with the always-on, remote-driven interface from spec section 6: Idle, PIN, Mirroring, Video, Audio, Settings/Troubleshooting, and First run.

**Architecture:** New package `io.github.jqssun.airplay.ui.tv`. `MainActivity` shows `TvApp` when `isTvDevice()` and jqssun's `MainScreen` otherwise. `MainScreen.kt` is left untouched so upstream merges stay clean. A pure function `resolveTvScreen()` turns ViewModel state into one `TvScreen`. Screens are stateless composables (state plus callbacks), tested with Compose UI tests on the TV over ADB. `TvApp` is the only place that touches `MainViewModel`. The mirroring `VideoSurfaceView` stays composed under every screen except Video, so its `AndroidView` is never reparented (jqssun documents a crash in `MainScreen.kt:103`).

**Tech Stack:** Kotlin 2.1, Jetpack Compose (BOM 2024.12.01, Material3), Hilt, JUnit 4, Compose UI Test (instrumented), ADB over Wi-Fi to the Hisense.

**Spec:** `docs/superpowers/specs/2026-10-03-airplay-tv-receiver-design.md` (section 6; section 7.1 for tests)

**Depends on:** Plan 1 Tasks 1–2 (build, `./gw`, `ServerName`, JUnit), which are complete on branch `plan-1-foundation`. This plan continues on that branch.

## Global Constraints

- Every screen is fully usable with a D-pad remote; no touch-only interactions on TV.
- The receiver is always on: no Start/Stop control on TV.
- `MainScreen.kt`, `SettingsScreen.kt`, `VideoControls.kt` and `ui/gestures/*` are not modified (phone path; upstream-merge friendly).
- Kotlin package/namespace stays `io.github.jqssun.airplay`; the new code lives in `io.github.jqssun.airplay.ui.tv`.
- Only the TV UI is in scope; no changes to `service/`, `renderer/` or native code.
- "AirPlay" appears only descriptively; About shows "Not affiliated with Apple Inc. AirPlay is a trademark of Apple Inc."
- Primary device: Hisense `SmartTV 4K FFM`, 192.168.1.248, Android 10 (API 29). Visual checks are done there with `adb exec-out screencap`.
- Gradle via `./gw`. Instrumented tests run on the TV: `ANDROID_SERIAL=192.168.1.248:5555 ./gw :app:connectedDebugAndroidTest -Pandroid.injected.androidTest.leaveApksInstalledAfterRun=true`.

## Decisions taken in this plan (deviations from spec wording)

- **Compose for TV (`androidx.tv`) is not added.** Plain Compose Material3 plus jqssun's existing D-pad helpers (`dpadFocus`, `requestFocusUntilLanded`) already provide focus rings and traversal. Cost if wrong: swapping in `tv-material` components later is local to `ui/tv/`.
- **"<device> connected" toast reads "Device connected".** The service doesn't expose the sender's name.
- **Troubleshooting logs are view-only on TV.** Export uses Android's share sheet, which TVs usually lack; developers use `adb logcat` instead. The source-code URL in About is added in Plan 4, once the public repository exists.
- **"Disconnect" restarts the receiver** (stop + start), because UxPlay has no per-client disconnect. This is the same path `MainViewModel._applyByServerRestart` uses.
- **Background receiving uses a runtime check instead of a fixed choice.** The app checks `Settings.canDrawOverlays()` plus whether the system screen exists. Granted → nothing shown. Grantable → an "open automatically" button. Not available → a "keep Sideplay open" note. This works for every outcome of Plan 1 Task 3.

## Review Focus

1. **A session starting while you're in Settings or Troubleshooting** must take over the screen (mirroring must not play hidden behind a settings page). Tested in Task 7 (`TvAppContentTest.sessionOverridesSettingsRoute`).
2. **A PIN prompt during an active video or mirroring session** must show the PIN, or the user can't complete pairing. Tested in Task 1 (`pinWinsOverEverything`).
3. **Renaming the TV to blank, spaces only, or more than 50 bytes**: blank must be rejected, and long names truncated with `ServerName` rules (mDNS label limit). Tested in Task 5 (`renameRejectsBlankAndTruncatesLong`).
4. **Pressing Back on the confirmation dialog** must close the dialog, not disconnect or leave the app. Tested in Task 4 (`backOnDialogDismissesIt`).
5. **Returning from the system overlay-permission screen**: the Idle screen must re-check and hide the button once granted. `TvApp` re-reads the state in `LifecycleResumeEffect` (Task 7), and the device check in Task 8 Step 5 exercises it.

```kotlin
package io.github.jqssun.airplay.ui.tv

/** What the TV shows; derived from service state, never stored. */
sealed interface TvScreen {
    data object FirstRun : TvScreen
    data class Idle(val connecting: Boolean) : TvScreen
    data class Pin(val code: String) : TvScreen
    data object Mirroring : TvScreen
    data object Video : TvScreen
    data object Audio : TvScreen
}

data class TvSession(
    val firstRunDone: Boolean,
    val connectionCount: Int,
    val mirroringActive: Boolean,
    val audioOnly: Boolean,
    val videoPlaybackActive: Boolean,
    val videoSessionPending: Boolean,
    val pinCode: String?,
)

// pin first: pairing can't complete unless the code is visible
fun resolveTvScreen(s: TvSession): TvScreen = when {
    s.pinCode != null -> TvScreen.Pin(s.pinCode)
    s.videoPlaybackActive || s.videoSessionPending -> TvScreen.Video
    s.mirroringActive && !s.audioOnly -> TvScreen.Mirroring
    s.audioOnly && s.connectionCount > 0 -> TvScreen.Audio
    !s.firstRunDone -> TvScreen.FirstRun
    else -> TvScreen.Idle(connecting = s.connectionCount > 0)
}
```

```kotlin
package io.github.jqssun.airplay.ui.tv

fun formatPlaybackTime(ms: Long): String {
    val total = (ms.coerceAtLeast(0) / 1000)
    val h = total / 3600
    val m = (total % 3600) / 60
    val s = total % 60
    return if (h > 0) "%d:%02d:%02d".format(h, m, s) else "%d:%02d".format(m, s)
}
```

```kotlin
package io.github.jqssun.airplay.ui.tv

import java.net.Inet4Address
import java.net.InetAddress
import java.net.NetworkInterface

/** The TV's LAN IPv4, shown on the idle screen for troubleshooting. */
object LanAddress {
    fun pick(addresses: List<InetAddress>): String? =
        addresses.filterIsInstance<Inet4Address>()
            .filter { !it.isLoopbackAddress && !it.isLinkLocalAddress }
            .sortedByDescending { it.isSiteLocalAddress }
            .firstOrNull()?.hostAddress

    fun current(): String? = runCatching {
        NetworkInterface.getNetworkInterfaces()?.toList().orEmpty()
            .filter { it.isUp && !it.isLoopback }
            .flatMap { it.inetAddresses.toList() }
    }.getOrNull()?.let(::pick)
}
```

```kotlin
package io.github.jqssun.airplay.ui.tv

import android.content.Context
import android.content.Intent
import android.net.Uri
import android.provider.Settings

/** Whether the service may bring the app to the front when a device connects (Android 10+ background start rules). */
enum class OverlayAccess { GRANTED, GRANTABLE, UNAVAILABLE }

fun resolveOverlayAccess(canDraw: Boolean, settingsScreenExists: Boolean): OverlayAccess = when {
    canDraw -> OverlayAccess.GRANTED
    settingsScreenExists -> OverlayAccess.GRANTABLE
    else -> OverlayAccess.UNAVAILABLE
}

object OverlayPermission {
    fun intent(ctx: Context): Intent =
        Intent(Settings.ACTION_MANAGE_OVERLAY_PERMISSION, Uri.parse("package:${ctx.packageName}"))
            .addFlags(Intent.FLAG_ACTIVITY_NEW_TASK)

    fun access(ctx: Context): OverlayAccess = resolveOverlayAccess(
        canDraw = Settings.canDrawOverlays(ctx),
        settingsScreenExists = intent(ctx).resolveActivity(ctx.packageManager) != null,
    )
}
```

```kotlin
                    color = Color.White,

            }
```

```kotlin
            val cancelFocus = remember { FocusRequester() }

                onDismissRequest = { confirm = false },
```

```kotlin
import kotlinx.coroutines.delay

private const val CONTROLS_HIDE_MS = 4_000L

data class TvVideoState(
    val title: String,
    val playing: Boolean,
    val buffering: Boolean,
    val pending: Boolean,
    val positionMs: Long,
    val durationMs: Long,
)

@Composable
fun TvVideoScreen(
    state: TvVideoState,
    surface: @Composable () -> Unit,
    onTogglePlay: () -> Unit,
    onPlay: () -> Unit,
    onPause: () -> Unit,
    onSeekBy: (Long) -> Unit,
    onStop: () -> Unit,
) {
    val focus = remember { FocusRequester() }
    var controlsVisible by remember { mutableStateOf(true) }
    var keyTick by remember { mutableIntStateOf(0) }
    LaunchedEffect(Unit) { focus.requestFocusUntilLanded() }
    // any key or pause shows controls; they hide again while playing
    LaunchedEffect(keyTick, state.playing) {
        controlsVisible = true
        if (state.playing) {
            delay(CONTROLS_HIDE_MS)
            controlsVisible = false
        }
    }
    BackHandler { onStop() }

    Box(
```

```kotlin
package io.github.jqssun.airplay.ui.tv

import android.view.Surface
import androidx.compose.foundation.background
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.fillMaxSize

import androidx.compose.runtime.setValue

import androidx.compose.ui.graphics.Color
import androidx.compose.ui.platform.LocalContext
import androidx.lifecycle.compose.LifecycleResumeEffect
import io.github.jqssun.airplay.ui.VideoSurfaceView
import io.github.jqssun.airplay.viewmodel.MainViewModel

enum class TvRoute { HOME, SETTINGS, TROUBLESHOOTING }

/** Routing only; every screen is a slot so this can be tested without the service. */
@Composable
fun TvAppContent(
    screen: TvScreen,
    route: TvRoute,
    mirrorSurface: @Composable () -> Unit,
    firstRun: @Composable () -> Unit,
    idle: @Composable (connecting: Boolean) -> Unit,
    pin: @Composable (code: String) -> Unit,
    mirroring: @Composable () -> Unit,
    video: @Composable () -> Unit,
    audio: @Composable () -> Unit,
    settings: @Composable () -> Unit,
    troubleshooting: @Composable () -> Unit,
) {
    Box(Modifier.fillMaxSize().background(Color.Black)) {
        // kept composed (never moved) so frames have a surface the moment mirroring starts
        if (screen !is TvScreen.Video) mirrorSurface()
        when (screen) {
            TvScreen.FirstRun -> firstRun()
            is TvScreen.Idle -> when (route) {
                TvRoute.HOME -> idle(screen.connecting)
                TvRoute.SETTINGS -> settings()
                TvRoute.TROUBLESHOOTING -> troubleshooting()
            }
            is TvScreen.Pin -> pin(screen.code)
            TvScreen.Mirroring -> mirroring()
            TvScreen.Video -> video()
            TvScreen.Audio -> audio()
        }
    }
}

@Composable
fun TvApp(
    viewModel: MainViewModel,
    onSurfaceAvailable: (Surface) -> Unit,
    onSurfaceDestroyed: (Surface) -> Unit,
) {
    val context = LocalContext.current
    val firstRunDone by viewModel.firstRunDone.collectAsState()
    val connections by viewModel.connectionCount.collectAsState()
    val mirroring by viewModel.mirroringActive.collectAsState()
    val audioOnly by viewModel.audioOnly.collectAsState()
    val videoActive by viewModel.videoPlaybackActive.collectAsState()
    val videoPending by viewModel.videoSessionPending.collectAsState()
    val pinCode by viewModel.pinCode.collectAsState()
    val serverName by viewModel.serverName.collectAsState()
    val lanAddress by viewModel.lanAddress.collectAsState()

    var route by rememberSaveable { mutableStateOf(TvRoute.HOME) }
    var overlayAccess by remember { mutableStateOf(OverlayPermission.access(context)) }
    // re-check after returning from the system permission screen
    LifecycleResumeEffect(Unit) {
        overlayAccess = OverlayPermission.access(context)
        onPauseOrDispose { }
    }

    val screen = resolveTvScreen(TvSession(firstRunDone, connections, mirroring, audioOnly, videoActive, videoPending, pinCode))
    // a session ends any settings visit, so the next idle starts at home
    LaunchedEffect(screen !is TvScreen.Idle) { if (screen !is TvScreen.Idle) route = TvRoute.HOME }

    TvAppContent(
        screen = screen,
        route = route,
        mirrorSurface = {
            val aspect by viewModel.videoAspect.collectAsState()
            VideoSurfaceView(onSurfaceAvailable = onSurfaceAvailable, onSurfaceDestroyed = onSurfaceDestroyed, aspectRatio = aspect)
        },
        firstRun = { TvFirstRunScreen(serverName) { name, boot -> viewModel.completeFirstRun(name, boot) } },
        idle = { connecting ->
            TvIdleScreen(
                serverName = serverName,
                ipAddress = lanAddress,
                connecting = connecting,
                overlayAccess = overlayAccess,
                onOpenSettings = { route = TvRoute.SETTINGS },
                onAllowAutoOpen = { runCatching { context.startActivity(OverlayPermission.intent(context)) } },
            )
        },
        pin = { code -> TvPinScreen(code) },
        mirroring = { TvMirroringOverlay(onDisconnect = { viewModel.disconnectAll() }) },
        video = {
            val title by viewModel.videoTitle.collectAsState()
            val playing by viewModel.videoPlaying.collectAsState()
            val buffering by viewModel.videoBuffering.collectAsState()
            val position by viewModel.videoPositionMs.collectAsState()
            val duration by viewModel.videoDurationMs.collectAsState()
            val aspect by viewModel.videoPlaybackAspect.collectAsState()
            TvVideoScreen(
                state = TvVideoState(title, playing, buffering, pending = !videoActive && videoPending, position, duration),
                surface = {
                    VideoSurfaceView(
                        onSurfaceAvailable = { viewModel.onVideoPlaybackSurfaceAvailable(it) },
                        onSurfaceDestroyed = { viewModel.onVideoPlaybackSurfaceDestroyed(it) },
                        aspectRatio = aspect,
                    )
                },
                onTogglePlay = { viewModel.toggleVideoPlayPause(showOverlay = false) },
                onPlay = { viewModel.setVideoPlaying(true, showOverlay = false) },
                onPause = { viewModel.setVideoPlaying(false, showOverlay = false) },
                onSeekBy = { viewModel.seekVideoBy(it) },
                onStop = { viewModel.stopVideoPlayback() },
            )
        },
        audio = {
            val track by viewModel.trackInfo.collectAsState()
            TvAudioScreen(track.title, track.artist, track.album, track.coverArt)
        },
        settings = {
            val requirePin by viewModel.requirePin.collectAsState()
            val boot by viewModel.bootAutoStart.collectAsState()
            val h265 by viewModel.h265Enabled.collectAsState()
            TvSettingsScreen(
                state = TvSettingsState(serverName, requirePin, boot, h265),
                onRename = { viewModel.setServerName(it) },
                onRequirePin = { viewModel.setRequirePin(it) },
                onBootAutoStart = { viewModel.setBootAutoStart(it) },
                onH265 = { viewModel.setH265Enabled(it) },
                onOpenTroubleshooting = { route = TvRoute.TROUBLESHOOTING },
                onBack = { route = TvRoute.HOME },
            )
        },
        troubleshooting = {
            val port by viewModel.serverPort.collectAsState()
            val debug by viewModel.debugInfo.collectAsState()
            val logs by viewModel.logs.collectAsState()
            val version = remember {
                runCatching { context.packageManager.getPackageInfo(context.packageName, 0).versionName }.getOrNull().orEmpty()
            }
            TvTroubleshootingScreen(
                state = TvTroubleshootingState(lanAddress, port, version, debug.videoCodec, logs),
                onBack = { route = TvRoute.SETTINGS },
            )
        },
    )
}
```
